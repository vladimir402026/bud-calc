Норми розрахунку каркаса для гіпсокартону

Калькулятор розраховує матеріали за стандартною технологією монтажу (крок основних профілів CD становить 600 мм для стін та 400–500 мм для стелі):

  • Направляючий профіль (UD): монтується по всьому периметру конструкції із запасом 10% на стикування.
  • Підвіси: встановлюються вздовж кожного профілю CD з кроком 60–70 см (по 2 дюбелі на кожен підвіс).
  • Саморізи: на один стандартний лист 1.2×2.5 м витрачається близько 50–60 саморізів 3.5×25 мм (при двошаровій обшивці для другого шару використовують довші саморізи 3.5×35 мм).
